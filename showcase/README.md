# Kelp & Compass

A fictional sea-kayaking trip site that combines about 60 Modern Web Guidance guides in one
working website: Home, Trips, Trip details, Booking, Journal and Saved, all in `index.html`.

Turn on **Show guides** in the header to label each part of the page with the guide that
built it; each label links to that guide in the Modern Web Guidance Atlas (`site/`).
**Guides used here** in the footer lists them all.

`index.html` has no `<html>`/`<head>` wrapper because it's published as a claude.ai Artifact,
which adds one. Nothing is charged or sent: the booking form and comments are demos.
