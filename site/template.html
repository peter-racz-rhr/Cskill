    How the skill works

    Read the skill file

    1. Search

      The agent runs a 2–5 word query for one capability, like “light dismiss dialog”.

    2. Retrieve

      It pulls the matching guides, plus broad ones such as css or security.

    3. Verify

      It checks the code against the guide, including the fallbacks for features that aren't Baseline yet.

    4. Disclose

      It ends its answer with a “Modern Web Guidance” note naming each guide it applied.

    npx -y modern-web-guidance@latest search "light dismiss dialog"
