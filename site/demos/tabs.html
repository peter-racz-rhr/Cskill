Structure

HTML gives content its meaning: headings, lists, forms and the built-in controls that work with a keyboard for free.

Presentation

CSS lays things out and styles them. Container queries let a component respond to the space it's given.

Behaviour

JavaScript adds what markup can't do alone, such as fetching data or reacting to what the user types.

Arrow keys move between tabs; Tab moves into the panel. Inactive panels use hidden="until-found", so find-in-page for “container” switches tabs.
